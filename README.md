# AstrBot GAY 浓度检测插件

娱乐向群聊整活插件：检测群友的「同性恋浓度」，附 Gay 王榜、CP 配对与友善科普。

- 作者：云晓
- 版本：1.0.1
- 许可证：MIT（详见 LICENSE）

> 本插件为善意玩笑向娱乐内容，评语保持轻松幽默；科普内容倡导尊重与平等，不针对任何群体。纯属娱乐，请勿当真。

## 功能

### 浓度检测（`/gay`）
- `/gay @对方` 或 `/gay 名字`：检测 TA 的浓度（0~100%）
- **每人每日一次固定**：同一天重复查询结果不变（哈希生成，跨天自动重抽），防止反复抽到满意为止
- 七档等级：钢铁直男 / 直男认证 / 略有潜力 / 深藏不露 / 弯道超车 / Gay 中之光 / 天选 Gay 王（1% 稀有）
- 每档多条评语随机；`/gay` 无参数时默认检测自己
- 支持从消息组件直接提取被 @ 者

### 连续检测称号
- 连续多日被检测自动累计天数并授予称号：
  - 3 天「入门弯友」· 7 天「七连铁 GAY」· 14 天「半月老弯」· 21 天「三周老司机」· 30 天「月度钉子户」
- 可通过配置 `streak_titles_enabled` 关闭

### Gay 王榜（`/gay榜`，别名 `/gay王榜`）
- 展示本群今日浓度排行 Top10（🥇🥈🥉）
- 揭晓「今日 Gay 王」；仅统计本群记录，跨群隔离

### CP 配对（`/cp`）
- `/cp @A @B` 或 `/cp A B`（也支持一个 @ + 一个名字混搭）
- 输出契合度（40~100%）+ 等级文案（天作之合 / 甜到发齁 / 配一脸 / 有点东西 / 塑料兄弟情）+ 自动生成的情侣名（双方名字各取前半拼接）
- 按「双方标识 + 日期」哈希：**当日结果固定且与顺序无关**

### 友善科普（`/gay 科普`）
- 随机输出一条 LGBTQ+ 尊重向小知识（内置 11 条），倡导平等友善的群聊氛围

## 指令表

| 指令 | 说明 |
|------|------|
| `/gay @对方` | 检测被 @ 者的今日浓度 |
| `/gay 名字` | 按名字检测 |
| `/gay` | 默认检测自己 |
| `/gay榜` | 本群今日 Gay 王榜 Top10（别名 `/gay王榜`） |
| `/cp @A @B` / `/cp A B` | CP 配对（契合度 + 情侣名） |
| `/gay 科普` | 随机友善小知识 |
| `/gay 帮助` | 显示帮助 |

指令兼容带 `/`、`／` 或不带斜杠的前缀。

## 配置

见 `_conf_schema.json`：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `keep_days` | int | `7` | 检测记录保留天数，过期自动清理 |
| `max_daily_records` | int | `1000` | 每日记录最大条数，超出清理最旧 |
| `streak_titles_enabled` | bool | `true` | 是否启用连续检测称号 |

配置脏值自动回退默认值，不会导致插件崩溃。

## 数据

存储于 `plugin_data/astrbot_plugin_gay/gay_data.json`（按日期 + 群 + 目标保存，含浓度/等级/评语/连续天数）。文件损坏时自动重置，不影响运行。
